# Heart & Soul 2.0.6 → Dynamic Calc

Installed calculator data: `backups/heartandsoul.js`. Open the calculator with
`?data=heartandsoul&gen=8&dmgGen=8&types=6&critGen=5&noSwitch=1` or choose
**Heart & Soul 2.0.6** in the game selector.

HnS uses `calc/mechanics/gen789.js` through the Gen 8 engine setting. The settings
menu's **Phys/Spec Split** toggle defaults to enabled and persists separately for
HnS. Disabling it applies the original type-based damage categories (including
Fairy as special), while keeping the same damage engine. Status moves stay status.

The export contains 1,427 species/forms, 934 moves, 651 nonempty HnS trainer
records and four HnS partner teams: 1,844 Pokémon total. It reads the ARM ELF's
compiled tables and follows pointers to learnsets and parties. The compiler
supplies struct offsets and bitfield masks, so outdated offset comments,
unselected preprocessor branches and duplicate form names cannot silently
replace the runtime data. Source revision: `167aa6d537b109bb229c231ddce4616974c4da71`
(2.0.6).

## Rebuild and extract

Requires Python 3, Node.js, the source repository's build dependencies and an
ARM GCC toolchain. Run from the calculator repository:

```sh
make -C ../pokehns-expansion release BUILD=hns -j8
python3 tools/heartandsoul/export.py \
  --source ../pokehns-expansion \
  --elf ../pokehns-expansion/pokehns-release.elf \
  --out tools/heartandsoul/output
python3 tools/heartandsoul/verify_documentation.py \
  --documentation ../pokehns-expansion-documentation \
  --output tools/heartandsoul/output
```

Pass `--compiler /path/to/arm-none-eabi-gcc` when the build toolchain differs from
the compiler on PATH. The source Makefile can use the toolchain in `DEVKITARM`.

Defaults match the supplied save: **Fairy typing, modern learnsets and Legendary
abilities enabled**. Alternate exports support `--no-fairy`, `--learnsets gen3`
and `--no-legendary-abilities`. Use separate output directories for these
profiles. Trainer moves omitted in the source are generated by the game's
level-up algorithm, including its duplicate-move handling and level-0 exclusion.

The optional Legendary abilities mode replaces slot 0 for Articuno, Zapdos,
Moltres, Mewtwo, Raikou, Entei, Suicune, Lugia and Ho-Oh. The export applies that
override to species and trainer Pokémon, including explicitly selected abilities
that resolve to slot 0. Save imports read the mode directly from SaveBlock3.

Outputs include `heartandsoul.js`/`.json`, `trainers.json` (source identifiers and
baseline/effective abilities), `species.raw.json` (both learnset modes),
`heartandsoul.order.js`, `heartandsoul_constants.js`, `manifest.json` and
`documentation_comparison.json`. Generated files under `output/` are ignored.
The installed JS data, reader constants, tools and sample fixture are tracked.
The checked-in `documentation_comparison.json` records this verification run;
copy the regenerated report from `output/` when refreshing it.
To install regenerated files:

```sh
cp tools/heartandsoul/output/heartandsoul.js backups/heartandsoul.js
cp tools/heartandsoul/output/heartandsoul.order.js backups/trainer_orders/heartandsoul.js
cp tools/heartandsoul/output/heartandsoul_constants.js js/savereaders/save_constants/heartandsoul_constants.js
cp tools/heartandsoul/output/documentation_comparison.json tools/heartandsoul/documentation_comparison.json
```

## Difficult Teams variant

**Heart & Soul Difficult Teams** is a second option in the same game family,
using `?data=heartandsouldifficult&gen=8&dmgGen=8&types=6&critGen=5&noSwitch=1`.
It shares the Gen 7–9 engine and split toggle but has its own backup, trainer
navigation and save ability constants. Source revision:
`8d28c37e295167efcebfe3f47ec1b48a3b3e8dcf` in
`../pokemonHnS-Difficult-Teams-2.0`.

The fork changes more than teams: 24 species have ability changes, 14 have stat
changes, six have typing changes and seven have modern learnset changes. The
934 move records match the base game. It modifies 480 existing trainer parties,
adds three trainer records, and shifts the 22 post-OBC trainer IDs by three.
The export contains 658 trainer/partner records and 2,497 Pokémon, with actual
source natures and gender policies.

Twenty-four battles have source-defined starting conditions. Selecting these
trainers loads weather, terrain and opponent Tailwind where applicable. Teams
with two player-side Toxic Spikes layers display that condition beside the
trainer; the calculator does not automatically poison Pokémon switching in.
The save layouts are identical, but the reader chooses the variant's ability
table. No separate Difficult Teams save was supplied; compatibility is checked
using the common layout, the sample save and an encrypted ability-slot mutation.
`variant_comparison.json` records the detailed differences from the base game.
The official documentation describes the base game; the modified teams are
verified against the fork's compiled tables.

```sh
make -C ../pokemonHnS-Difficult-Teams-2.0 release BUILD=hns -j8
python3 tools/heartandsoul/export.py \
  --source ../pokemonHnS-Difficult-Teams-2.0 \
  --elf ../pokemonHnS-Difficult-Teams-2.0/pokehns-release.elf \
  --out tools/heartandsoul/output-difficult \
  --title 'Heart & Soul Difficult Teams' \
  --constants-variable heartAndSoulDifficultSaveConstants
cp tools/heartandsoul/output-difficult/heartandsoul.js backups/heartandsouldifficult.js
cp tools/heartandsoul/output-difficult/heartandsoul.order.js backups/trainer_orders/heartandsouldifficult.js
cp tools/heartandsoul/output-difficult/heartandsoul_constants.js js/savereaders/save_constants/heartandsoul_difficult_constants.js
python3 tools/heartandsoul/compare_variants.py \
  --base tools/heartandsoul/output \
  --difficult tools/heartandsoul/output-difficult \
  --report tools/heartandsoul/variant_comparison.json
```

## Nature and gender

`trainerproc` emits **Hardy** when nature is omitted. All trainer sets have a
nature, including the 50 non-Hardy sets in this export. The docs print 18 explicit
natures in their smaller major-battle selection.

Omitted Pokémon gender becomes `TRAINER_MON_RANDOM_GENDER`, not the trainer's
gender. `battle_main.c` chooses a gender before adjusting personality for the
specified nature. Exported records contain `gender`, `gender_policy` and
`gender_options`. Mixed-gender species with random generation show **Random** in
the calculator; single-gender and genderless species resolve to M/F/N. The four
explicit gender entries are preserved. Totals: 1,605 random, 59 male, 61 female,
119 genderless. Choose Male/Female once a random opponent's actual gender is
known; the Random selection applies a neutral gender for gender-dependent
calculations.

The Sabrina/Mr. Mime special-case in `battle_main.c` compares the address of an
inline `trainerName` array with a separate compound literal. That comparison does
not identify Sabrina in this compiled table, so her unspecified Mr. Mime gender
remains random.

## Save reader and verification

`js/savereaders/savereader_heartandsoul.js` supports raw 64/128 KiB saves and the
sample's 16-byte trailer. It validates complete slots, selects the newest save
counter, falls back to the previous valid slot, joins sectors by logical ID,
checks Pokémon checksums, decrypts/unshuffles all substructures, masks expanded
species/move/item/experience fields and reads the two-bit ability selector.
It preserves PID gender, mint-adjusted stat nature, original nature, nicknames,
friendship, hyper-trained effective IVs, eggs and shiny overrides.

All 14 PC boxes and fusion storage are decoded. As in the existing Gen 3 readers,
Box 14 is imported as the death box. The supplied save has six party Pokémon,
25 live Box 1 Pokémon and two dead Box 14 Pokémon. Party species, nicknames,
level 31, genders and HP match the attached party screenshot; all 25 Box 1
species match the attached storage screenshot in slot order. Ability names are
normalized to calculator names, including Dry Skin, Thick Fat and Keen Eye.

The official documentation comparison checks 1,305 displayed species/forms,
all 934 moves, and 101 major/partner battles with 501 Pokémon. It compares stats,
types, normal/hidden abilities, size, growth, gender ratios, both learnset modes,
trainer species, levels, items, abilities, moves and printed natures. Cosmetic
forms omitted from the displayed docs remain in the full source export. Older
move spellings such as Faint Attack, Vice Grip and Hi Jump Kick are normalized.
The docs' baseline abilities are compared to baseline source slots; mode-specific
Legendary overrides are listed separately in the report.

The comparison checks 19,446 fields. Stats, types, abilities, growth, gender
ratios, modern learnsets, all move fields and the documented trainer teams match.
There are 28 source/documentation differences: four Minior Meteor forms show
3.2 m in the docs versus 0.3 m in the compiled source, and 24 species/forms have
different optional Gen 3 learnsets (Floette Red, Genesect, Mothim Plant, Spewpa
Icy Snow and all 20 Vivillon forms). These Gen 3 table entries are null in the
compiled source, so `GetSpeciesLevelUpLearnset` falls back to their modern
learnsets. The export retains the runtime values and the report lists both sides.
With Legendary abilities enabled, Blue's Articuno uses Water Veil instead of
the baseline Pressure shown in the docs.

```sh
node --test calc/test/heartandsoul-savereader.test.cjs
npx cypress run --spec cypress/e2e/calc-ui/heartAndSoul.cy.js \
  --config baseUrl=http://127.0.0.1:3001 --browser electron
```

The Cypress check requires the calculator served at port 3001. It verifies data
loading, Random gender selection, source move targeting, split-toggle persistence
and damage changes, and the actual upload
pipeline, including all 31 live imports, nicknames, abilities and two deaths.
It also checks Difficult Teams data, save profile selection and starting fields.

## Scope

Trainer navigation follows record ID order, including rematches and starter
branches; it does not claim to be a story walkthrough. Battle partner IDs use
the game's `MAX_TRAINERS_COUNT + partner` namespace.

The calculator runs its existing Gen 8 engine with Gen 3 critical-hit multiplier.
Heart & Soul mixes generation rules and configurable challenges; this extraction
does not implement its complete damage/AI engine, badge boosts, scripted stat
scaling, or all challenge modes. Trainer IVs/EVs and friendship remain the actual
source values. The existing calculator assumes conventional Return power when
loading that move, even though trainer friendship is usually zero in the source.
Randomized ability/type saves are rejected because these require randomized data.
Saves using a different Fairy/learnset/Legendary profile require a matching
calculator export. Emulator save states are outside this reader's format.
